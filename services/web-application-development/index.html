Common questions

What is the difference between a website and a web application?

A website mainly presents information. A web application lets users log in, enter data and get results, such as a dashboard, portal or booking system.

Can you build only the backend?

Yes. I can build and document an API for your existing website or mobile app.

Who maintains it after launch?

I can keep maintaining and improving the application after launch, and the code is structured so another developer could take over.
