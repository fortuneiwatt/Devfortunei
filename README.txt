Fortune portfolio
Open index.html in a browser. No build step.

Files: index.html, css/styles.css, js/main.js, images/
Images: replace any file in images/ with your own (same name), or edit the src in index.html / js/main.js. JPG, PNG and WebP work; update the extension in the src if you change it.
Links: set email, github and linkedin in the CFG line at the top of js/main.js.
Contact form: not included (needs a backend or email service).
